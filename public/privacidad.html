Privacidad

Letterbondi publica el nombre de usuario, la línea, la fecha del viaje, la puntuación y el texto que decidas compartir. No solicita tu nombre real ni tu correo electrónico.

Qué se guarda

Las cuentas guardan un nombre de usuario y un hash seguro de la contraseña. Las sesiones usan una cookie HttpOnly. Las publicaciones anónimas usan un identificador aleatorio guardado en otra cookie para limitar abuso y permitir eliminar la reseña desde el mismo navegador. Las direcciones IP se usan temporalmente en memoria para aplicar límites de uso y no se guardan en la base.

Para qué se usa

Los datos se usan únicamente para operar el diario público, mantener la sesión, mostrar estadísticas y proteger el servicio contra abuso. No se venden ni se usan para publicidad.

Control de tus datos

Podés eliminar tus reseñas desde el navegador donde las publicaste o eliminar tu cuenta completa. Al eliminar la cuenta también se eliminan sus sesiones, relaciones y reseñas. Las identidades anónimas sin publicaciones se eliminan después de 90 días de inactividad. Los backups operativos pueden conservar una copia temporal hasta completar su rotación.
